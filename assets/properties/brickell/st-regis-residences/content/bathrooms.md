# Bathrooms

Primary bathrooms have been designed as private wellness retreats, featuring luxurious finishes and spa-inspired layouts.

Features include:

- Travertine stone surfaces
- Freestanding soaking tubs
- Dornbracht fixtures
- Toto Washlet systems
- Dual vanities
- Walk-in showers
- Natural light in select residences

Secondary bathrooms continue the same design language with porcelain flooring and elegant stone counters.
